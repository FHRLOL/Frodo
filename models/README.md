# 🤖 Локальные модели для Frodo AI Mentor

В этой директории размещаются локальные квантованные веса моделей формата GGUF для инференса через `llama-server`.

> [!NOTE]
> Сами файлы весов (`*.gguf`) добавлены в `.gitignore` и не загружаются в Git-репозиторий из-за большого объема.

---

## 1. Модель эмбеддингов: `EmbeddingGemma 2`

- **Файл**: `embeddinggemma-2-Q8_0.gguf`
- **Порт инференса**: `http://127.0.0.1:8085`
- **Размещение**: Системная оперативная память (RAM, потребление ~2.5 ГБ)
- **Назначение**: Семантическая векторизация запросов и методических материалов для гибридного RAG.

---

## 2. Генеративная LLM: `Gemma 4 E4B-IT`

- **Файл**: `gemma-4-e4b-it-q4_k_m.gguf`
- **Порт инференса**: `http://127.0.0.1:8086`
- **Размещение**: Видеопамять GPU (NVIDIA RTX 5060 8 ГБ VRAM, занимает ~2.8 ГБ)
- **Свободно под KV-кэш**: > 4.4 ГБ (хватает на 6–8 одновременных пользователей с `-np 8` и `--cache-type-k q8_0`)
- **Назначение**: Потоковая генерация ответов наставника со скрытыми рассуждениями в тегах `<thought>` (Thinking Mode).
