# Frodo Frontend — Клиентская часть ИИ-наставника

> Данная директория содержит основу пользовательского интерфейса студента и подготовлена для полной переделки/кастомизации фронтенд-командой (на React / Next.js / Vue / Svelte / чистом JS).

---

## 1. Текущий прототип
- `index.html`: Чат-интерфейс диалога студента с наставником, отображение статуса базы знаний (`EmbeddingGemma 2`), плашек сносок и карточек материалов.
- `style.css`: Темная тема, адаптивная верстка, стили для Guardrail-отказов и цитирования.
- `app.js`: Логика общения с бэкендом (отправка `POST /api/query`, обработка статусов `REJECTED_BY_GUARDRAIL`, `GROUND_TRUTH_MATCH`, сносок).

---

## 2. API Контракт с бэкендом

Бэкенд запущен на `http://127.0.0.1:8000`.

### `POST /api/query`
Запрос от студента:
```json
{
  "question": "Почему списки считаются изменяемым типом данных?"
}
```

Ответ бэкенда:
```json
{
  "question": "Почему списки считаются изменяемым типом данных?",
```

### `GET /api/benchmark`
Возвращает массив 7 контрольных вопросов (позитивные + провокации) с эталонами и флагами `expected_in_docs`.

### `GET /api/health`
Проверка состояния сервера, доступности `EmbeddingGemma 2` (порт 8085) и количества индексированных документов.
