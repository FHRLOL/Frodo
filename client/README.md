# Frodo AI Mentor — Клиентский интерфейс (Holad Design System)

Клиентский веб-интерфейс ИИ-наставника по курсу Python с полной поддержкой протокола LTI 1.1, ролевой модели (Студент / Преподаватель), динамических режимов наставничества (Сократ vs Мастер) и потокового вывода Server-Sent Events (SSE).

Интерфейс смонтирован в FastAPI по маршруту `/chat` (`http://localhost:8000/chat`).

---

## 1. Архитектура и Дизайн-система Holad

Интерфейс строго соответствует семантическим токенам и стандартам Holad Modern Media:
- **Цветовая палитра**:
  - `bg-background`: `#0b0f19` (глубокий темный фон)
  - `bg-card`: `#151b2b` (подложка карточек и панелей)
  - `border-border`: `rgba(255, 255, 255, 0.08)` (тонкие полупрозрачные границы)
  - `text-foreground`: `#f8fafc` (основной текст высокой контрастности)
  - `text-secondary`: `#94a3b8` / `#b3b3b3` (подписи и метаданные)
  - `bg-primary`: `#10b981` (акцентный изумрудный цвет, кнопки `text-black font-bold`)
  - Акцентные плашки: `bg-primary/10 text-primary border-primary/20`
- **Доступность WCAG 2.1 AA**:
  - Все интерактивные кнопки содержат атрибут `aria-label`.
  - Зона тача всех интерактивных элементов $\ge 36\text{px}$.
  - Контрастность текста $\ge 4.5:1$ (для ключевого текста $> 14:1$).
  - Семантическая разметка с корневым контейнером `<main>`.
  - Тонкий кастомный скроллбар `.custom-scrollbar`.

## 2. Реализованные экраны и функционал

### 1. Шапка (Header)
- Логотип `🧙‍♂️ Frodo AI Mentor` со статусом протокола `LTI 1.1`.
- Индикаторы статуса моделей: `EmbeddingGemma 2` (порт 8085) и `Gemma 4 E4B` (порт 8086) с анимацией пульсации.
- **Быстрый переключатель ролей LTI** (для демонстрации комиссии и локального тестирования):
  - `[ Войти как Студент ]` (студент `student_42`: Алексей Иванов)
  - `[ Войти как Преподаватель ]` (преподаватель `instructor_1`: Проф. Смирнов А.В.)
  - Мгновенное получение сессионного JWT и обновление прав в рантайме.

### 2. Экран Студента (Student View)
- **Селектор лабораторных работ**: переключение между Лабами 1, 2, 3 с отображением статуса (`⚪ not_started`, `🟡 in_progress`, `🟢 passed`) и баллов.
- **Динамический баннер текущего режима**:
  - 🟡 **Режим наставника (Сократ)** (если лаба не сдана): Наставник не пишет готовый код, а задает наводящие вопросы и указывает на логические нестыковки.
  - 🟢 **Режим углубления (Мастер)** (если лаба сдана): Разблокируется полный доступ к академическим решениям, синтаксису и коду для подготовки к защите.
- **Чат с потоковым выводом (Server-Sent Events к `POST /api/query/stream`)**:
  - Посимвольный вывод ответа в реальном времени с мерцающей кареткой.
  - Рендеринг Markdown и блоков кода с кнопкой «Копировать код».
  - Аккордеон рассуждений модели `Gemma 4 E4B` (`<thought>...</thought>`).
  - Интерактивный блок цитирования с раскрытием источника и строк по клику.
  - Метрики генерации: время первого токена (`TTFT ms`) и скорость генерации (`tok/s`).
- **Панель ввода**: многострочное поле (Enter — отправить, Shift+Enter — перенос строки), быстрые пресеты вопросов и кнопка очистки диалога.

### 3. Панель Преподавателя (Instructor Dashboard)
- **Вкладка 1: «Матрица сдачи лабораторных» (`GET /api/admin/students`)**:
  - Таблица всех студентов и лабораторных работ курса.
  - Интерактивный выпадающий селектор статуса сдачи для каждой лабы (`not_started`, `in_progress`, `passed`) с автоотправкой на `POST /api/admin/student/progress`.
  - Мгновенная разблокировка Режима Мастера: смена статуса на `passed` сразу активирует Мастер-режим у студента!
- **Вкладка 2: «Анализ пробелов (Gap Analysis)» (`GET /api/admin/unanswered`)**:
  - Список вопросов студентов, отклоненных Guardrail (попытки Prompt Injection или релевантность $< 0.42$).
  - Отображает дату, вопрос, автора, скор релевантности и причину отсечения.
- **Вкладка 3: «База знаний (RAG Manager)»**:
  - Статус гибридного векторного хранилища (SQLite FTS5 + Dense Vector).
  - Список методических материалов курса (`data_structures.md`, `exceptions.md`, `op_exp.md`).
  - Кнопка «Переиндексировать базу знаний» (`POST /api/reindex`) с логом обработанных чанков.

## 3. Файловая структура `client/`
- `index.html` — семантическая разметка (Tailwind CDN, Marked.js, WCAG 2.1 AA разметка).
- `style.css` — стили Holad Design System, custom-scrollbar, токены, аккордеоны цитирования и анимации toast-уведомлений.
- `app.js` — клиентское SPA-приложение: SSE парсер, управление токенами JWT, LTI role switcher, реактивный интерфейс студента и преподавателя.
