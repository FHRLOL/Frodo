# Frodo — ИИ-наставник

Интерфейс учебного ИИ-наставника по макету Figma. React + Vite, чистый CSS, раскладка на flexbox, адаптив от 390 до 1440 px. Бэкенда нет: ответы и данные — моки.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`, предпросмотр: `npm run preview`, линт: `npm run lint`.

Тесты: `npm test` (однократный прогон), `npm run test:watch` (watch-режим). Стек: Vitest + jsdom + React Testing Library + user-event.

## Тесты

Покрыты маршрутизация, чат, компоненты и страницы преподавателя — 32 теста в 8 файлах:

| Файл | Что проверяет |
|---|---|
| `src/App.test.jsx` | маршруты, переходы из сайдбара, возврат по логотипу, редирект с неизвестного адреса |
| `src/pages/ChatPage.test.jsx` | поиск → ответ, полный ответ и подсказки, композер, панель источника, ответ «нет в материалах», сброс чата, связь формата с «Доступом студентов» |
| `src/pages/TeacherAccess.test.jsx` | студент и форматы, смена формата, пояснение и ссылка в чат |
| `src/pages/TeacherActivity.test.jsx` | статистика, бары тем, вопросы без ответа, ссылка на материалы |
| `src/pages/TeacherMaterials.test.jsx` | таблица, выбор лабораторной, имя загруженного файла |
| `src/components/FormatSelect.test.jsx` | раскрытие меню, выбор, закрытие по клику вне и Escape |
| `src/components/Composer.test.jsx` | отправка с обрезкой пробелов, пустой ввод, блокировка во время поиска |
| `src/components/SourcePanel.test.jsx` | полный/подсказочный режим, закрытие, инлайн-вариант |

Тестовое окружение настраивается в `vite.config.js` (`environment: 'jsdom'`, `setupFiles`), матчеры jest-dom подключаются в `src/test/setup.js`, обёртка `MemoryRouter` — в `src/test/renderApp.jsx`.

## Маршруты

| Путь | Экран |
|---|---|
| `/` | Чат студента: пустое состояние, поиск, ответ с цитатами, подсказки, ответ без материала, панель источника |
| `/teacher` | Кабинет преподавателя: активность курса |
| `/teacher/materials` | Материалы курса и загрузка файла |
| `/teacher/access` | Доступ студентов и выбор формата ответа |

## Что работает

- Вопрос из подсказок или композера → состояние «Ищу ответ в методичке…» → ответ через 1.2 с.
- Ответ зависит от формата: на странице «Доступ студентов» переключите «Полный ответ / Подсказки», затем откройте чат — бейдж и текст ответа изменятся.
- «Открыть» у карточки источника открывает панель методички на десктопе и инлайн-блок на мобильном.
- «Новый чат» сбрасывает историю.
- В «Материалах» можно выбрать файл (имя показывается под формой), в «Доступе» — формат из выпадающего меню.

## Структура

```
src/
  components/   Sidebar, Topbar, Composer, SourcePanel, FormatSelect, Logo, Layout, Rich
  pages/        ChatPage, TeacherActivity, TeacherMaterials, TeacherAccess
  data/mock.js  курсы, вопросы, ответы, цитаты, статистика, студенты
  styles/       tokens.css (палитра, шрифты), base.css (reset), app.css (все блоки и адаптив)
  context.js    общий формат ответа (full / hints)
```

Токены: фон `#F6F3ED`, сайдбар `#263C35`, акцент `#85334E`, зелёные бейджи `#E5EEE7`, розовые подложки `#F1E7EA`, персиковые цитаты `#FFF2E6`. Шрифты — Golos Text и IBM Plex Mono (Google Fonts).

Адаптив: до 900 px сайдбар скрывается, появляется мобильный топбар с логотипом, подсказки становятся карточками, кнопка отправки — круглой, источник открывается инлайн. У преподавателя на мобильном появляется горизонтальное меню разделов.
