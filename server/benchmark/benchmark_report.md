- **Гибридный скор релевантности**: `0.564`
- **Эталонный ответ (Ground Truth)**:
  > Список считается изменяемым типом данных, поскольку после его создания можно добавлять, удалять и искать элементы. ### 4. [q4] Как работает конструкция try..except в Python и при каком условии выполняется блок else?
- **Ожидаемый источник**: `exceptions.md, строки 36–55`
- **Найденный фрагмент**: `exceptions.md`, раздел «Обработка исключений», строки `35–58`
- **Гибридный скор релевантности**: `0.535`
- **Эталонный ответ (Ground Truth)**:
  > Команды, которые могут вызвать исключения, помещаются в блок try, а обработчики соответствующих исключений — в блок except. Обработчик может предназначаться для одного исключения или списка исключений. Если исключение не обработано, стандартный обработчик Python останавливает выполнение программы и выводит сообщение об ошибке. Блок else, если он добавлен, выполняется тогда, когда исключений не возникает.
- **Результат проверки**: Найден верный чанк: exceptions.md (строки 35–58)
